# Screenshots do Aplicativo

Esta pasta contém screenshots do aplicativo My Challenge - Movies App.

## Como Adicionar Screenshots

1. Execute o aplicativo em um dispositivo ou emulador
2. Navegue pelas telas principais
3. Capture screenshots das seguintes telas:
   - `splash_screen.png` - Tela inicial (Splash Screen)
   - `movie_list.png` - Lista de filmes populares
   - `movie_search.png` - Resultados de pesquisa
   - `movie_details.png` - Detalhes do filme
   - `favorites_list.png` - Lista de favoritos
   - `favorites_empty.png` - Tela de favoritos vazia
   - `error_connection.png` - Tela de erro de conexão
   - `error_generic.png` - Tela de erro genérica

## Dicas para Screenshots

- Use um dispositivo ou emulador com resolução adequada (pelo menos 1080x1920)
- Capture em modo claro (light mode) para melhor visualização
- Certifique-se de que os screenshots mostram funcionalidades importantes
- Use nomes descritivos para os arquivos
